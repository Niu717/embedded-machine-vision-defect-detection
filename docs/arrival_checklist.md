# 摄像头到货后的 30 分钟验收清单

1. 将摄像头直接接入笔记本 USB，等待 Windows 自动安装 UVC 驱动。
2. 双击项目根目录的 `run_camera.bat`；出现预览窗口即为识别成功。
3. 将镜头垂直对准白纸，手动调焦，确认画面中心和边缘清晰。
4. 安装 OK65LED 环形灯，亮度先调到 40%–60%，避免反光过曝。
5. 让瓶盖位于镜头下方约 12–15 cm，确保其占画面宽度 40%–60%。
6. 按 `S` 分别保存至少 10 张正常件、10 张缺陷件图像。
7. 将保存的图片和实际安装照片发给我；我将据此调整阈值、缺陷面积和拍摄距离。

验收阶段尚不连接 STM32 与舵机。先确保图像稳定，再进入串口和执行机构联调。
